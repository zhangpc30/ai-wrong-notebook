# AI 公考错题本微信小程序

可直接导入微信开发者工具的原生小程序工程。

## 已实现

- 相机拍照和相册选择
- 图片预览、重新选择
- 上传前压缩、20 MB 大小保护、分阶段进度展示
- 上传到统一后端 `POST /api/analyze`
- 分析加载、错误和重试提示
- 完整 Schema 结果展示与逐项编辑
- 多题图片识别结果拆分保存
- 基础后端 JSON 与扩展字段安全归一化
- 本地错题保存、全文搜索、多维筛选、收藏、批量管理、详情、编辑、删除和重新分析
- 详情页直接更新备注和掌握程度
- 基于掌握程度和优先级的“今日复习”队列
- 遮挡答案自测、掌握度反馈和 AI 同类题加练
- 首页掌握率、待复习数量、收藏数和薄弱模块统计
- 微信登录、本地错题首次迁移与多端双向同步
- 云端题目图片补传，离线或同步失败时继续使用本地模式
- 首页云同步状态提示，以及 JSON 备份导出和剪贴板恢复
- 后端地址配置与 `/health` 健康检查
- JSON 备份复制

本地错题统一保存在 `mistakes` storage key 中。旧版本
`public_exam_questions_v1` 数据会在首次读取时自动迁移。

## 导入

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本 `mini-program` 文件夹。
4. 将 `project.config.json` 中的 `touristappid` 替换为正式小程序 AppID。

正式 AppID 必须与后端 `.env` 中的 `WECHAT_APP_ID` 一致，并在微信公众平台生成
对应的 AppSecret 配置到后端。AppSecret 不能写入小程序代码。

## 域名配置

在微信公众平台的“开发管理 → 开发设置 → 服务器域名”中，将部署后的 HTTPS 域名加入：

- `request` 合法域名
- `uploadFile` 合法域名
- `downloadFile` 合法域名（用于跨设备显示云端题目图片）

小程序设置页只填写域名根地址，例如：

```text
https://ai.example.com
```

不要填写 `/api/analyze`，也不要在小程序代码中配置模型 API Key。

## 开发环境联调

微信开发者工具中可以临时勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”，
使用局域网或本机代理地址联调。真机预览和正式发布必须使用已备案、已配置的 HTTPS 域名。
